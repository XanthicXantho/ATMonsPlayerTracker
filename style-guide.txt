XANTHO HUB — STYLE GUIDE
=========================
Last updated: 2026-05-07


COLOR PALETTE
-------------
--bg        #101116     Base dark (nav background, fallback)
--surface   #18191f     Card/panel backgrounds
--border    #26272e     Borders between elements
--accent    #d4a053     Warm gold — hero title, active nav, sort indicators
--link      #7ba4c9     Muted blue — links, interactive text
--text      #d4d4d8     Light gray — main body text
--muted     #6b6d76     Dim gray — secondary text, descriptions, footer
--pending   #94a3b8     Slate — pending status (tracker only)
--denied    #ef4444     Red — denied/error states (tracker only)
--accepted  #22c55e     Green — accepted/success states (tracker only)

Background uses a single linear gradient:
  linear-gradient(180deg, #0a0c16 0%, #0d0f1a 40%, #111228 100%)


TYPOGRAPHY
----------
Font: Outfit (Google Fonts)
  Weights: 300 (light), 400 (regular), 500 (medium), 600 (semibold)

  Hero title:     600, 40px (28px mobile)
  Page headings:  600, 24px (20px mobile)
  Card titles:    600, 14px
  Nav links:      500, 13px (12px mobile)
  Section labels: 500, 13px, uppercase, letter-spacing 0.5px
  Body text:      400, 16px (base)
  Descriptions:   300, 14-15px
  Footer:         300, 13px

Google Fonts import:
  https://fonts.googleapis.com/css2?family=Outfit:wght@300;400;500;600&display=swap

Fallback stack: 'Outfit', -apple-system, sans-serif


CARD PATTERN
------------
  background: var(--surface)
  border: 1px solid var(--border)
  border-radius: 10px

Interactive cards add:
  transition: border-color 0.15s
  On hover: border-color: #3a3b44


BADGE PATTERN (status indicators, tracker only)
------------------------------------------------
  display: inline-flex; align-items: center; gap: 6px
  padding: 2px 10px; border-radius: 4px
  font-size: 13px; font-weight: 500

  Pending:   bg rgba(148,163,184,0.08), border rgba(148,163,184,0.2), color var(--pending)
  Denied:    bg rgba(239,68,68,0.08),   border rgba(239,68,68,0.2),   color var(--denied)
  Accepted:  bg rgba(34,197,94,0.08),   border rgba(34,197,94,0.2),   color var(--accepted)


NAV BAR
-------
  Sticky, top: 0, z-index: 10
  background: var(--bg), border-bottom: 1px solid var(--border)
  Links: Outfit 500 at 13px, mixed case, letter-spacing 0.5px
  Active link: var(--accent)
  Hover: var(--text)
  External links: include an 11x11 SVG external-link icon (stroke, currentColor, opacity 0.4)


SECTION HEADINGS
----------------
  Font: Outfit 500, 13px, uppercase, letter-spacing 0.5px
  Color: var(--muted)
  No decorators (no // wrapping)


ANIMATIONS & EFFECTS
--------------------
Glitter stars (canvas):
  Gold-toned star characters falling slowly
  Colors: #f59e0b, #fcd34d, #fbbf24
  Small (8-18px), slow (0.15-0.45 speed), low opacity (0.15-0.45)
  No glow/shadow — just flat colored text
  6 seeded on load, 3% chance to spawn per frame
  No fog — stars only

Entrance animations:
  fadeIn — table rows slide in from left (tracker), 0.3s ease


LAYOUT
------
  Max content width: 640-680px, centered with margin: 0 auto
  Section padding: ~48-72px bottom between sections
  Responsive breakpoints:
    600px — smaller fonts, 2-column card grid, compact padding
    380px — single-column card grid


SPACING CONVENTIONS
-------------------
  Nav: padding 14px 20px per link, no outer padding
  Hero: 96px top, 72px bottom (64px/48px on mobile)
  Hub cards: 36px 20px
  Table cells: 10px 16px
  Stats chips: 6px 14px
  Updates card: 24px 28px
  Footer: 48px bottom


NOTES FOR FUTURE EDITS
-----------------------
  - All colors are CSS custom properties in :root
  - Single font (Outfit) loads from Google Fonts
  - New pages should include the same nav, canvas, and :root variables
  - The hub grid auto-fits cards — just add more elements
  - The updates section is a placeholder — replace the inner content freely
  - External links use target="_blank" rel="noopener"
  - Internal links are relative paths (e.g., tracker.html)
  - No glassmorphism, no text-shadow glows, no backdrop-filter on content
