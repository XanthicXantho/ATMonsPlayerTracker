XANTHO HUB — STYLE GUIDE
=========================
Last updated: 2026-05-26

Matches the Undertale-themed OBS stream overlay aesthetic.


COLOR PALETTE
-------------
--accent        #d4a053     Warm gold — hero accent, active nav, card hover, separator
--accent-dim    rgba(212,160,83,0.25)  Gold at 25% for gradient separator
--accent-glow   rgba(212,160,83,0.4)   Gold at 40% for glow effects
--bg            #000000     Pure black — card/nav backgrounds, UT battle-box fill
--bg-deep       #0a0a0f     Near-black panel variant
--bg-panel      #111118     Slightly lighter panel variant
--border-ut     #ffffff     White — UT battle-box style borders
--text          #ffffff     White — headings, titles
--text-dim      #71717a     Dim gray — descriptions, secondary text
--text-body     #d4d4d8     Light gray — body text
--soul-red      #ff0000     Red — Undertale soul heart

Background uses a single linear gradient:
  linear-gradient(180deg, #0a0c16 0%, #0d0f1a 40%, #111228 100%)


TYPOGRAPHY
----------
Two fonts:
  1. Determination (local woff2) — Undertale dialogue font
     Used for: hero title, nav links, card titles, section labels, placeholder text
  2. Outfit (Google Fonts) — clean sans-serif
     Used for: body text, card descriptions
     Weights: 300 (light), 400 (regular), 500 (medium), 600 (semibold)

  Hero title:     Determination, 56px (36px mobile), letter-spacing 3px
  Nav links:      Determination, 14px (12px mobile), letter-spacing 1px
  Card titles:    Determination, 18px, letter-spacing 1px
  Section labels: Determination, 16px, letter-spacing 1px
  Descriptions:   Outfit 300, 14px
  Body text:      Outfit 400, 16px (base)
  Footer:         Outfit, 13px

Font files:
  determination.woff2 (local, repo root)
  https://fonts.googleapis.com/css2?family=Outfit:wght@300;400;500;600&display=swap

Fallback stacks:
  --font-ut:    'Determination', monospace
  --font-clean: 'Outfit', sans-serif


CARD PATTERN (UT battle-box)
-----------------------------
  background: var(--bg)      (pure black)
  border: 3px solid var(--border-ut)  (white)
  border-radius: none (sharp corners)

Interactive cards add:
  transition: border-color 0.2s
  On hover: border-color: var(--accent) (gold)


NAV BAR
-------
  Sticky, top: 0, z-index: 10
  background: var(--bg), border-bottom: 2px solid var(--border-ut)
  Links: Determination at 14px, letter-spacing 1px
  Active link: var(--accent)
  Hover: var(--text)
  External links: include an 11x11 SVG external-link icon (stroke, currentColor, opacity 0.4)


HERO
----
  Red Undertale soul heart (CSS clip-path polygon) with soul-beat animation
  Title in Determination font, 56px, uppercase, white
  Followed by gold gradient separator (ut-sep)


UT SEPARATOR
------------
  height: 1px
  background: linear-gradient(90deg, transparent, var(--accent-dim) 20%, var(--accent) 50%, var(--accent-dim) 80%, transparent)
  max-width: 680px, centered


SECTION HEADINGS
----------------
  Font: Determination, 16px, letter-spacing 1px
  Color: var(--text-dim)
  Prefixed with Undertale-style "* " asterisk


ANIMATIONS & EFFECTS
--------------------
Glitter stars (canvas):
  Gold-toned star characters falling slowly
  Colors: #f59e0b, #fcd34d, #fbbf24
  Small (8-18px), slow (0.15-0.45 speed), low opacity (0.15-0.45)
  No glow/shadow — flat colored text
  6 seeded on load, 3% chance to spawn per frame

Soul heart:
  soul-beat — scale 1 to 1.12, 2.5s ease-in-out infinite

Entrance:
  fade-up — opacity 0 + translateY(10px) to visible, 1.2s ease


LAYOUT
------
  Max content width: 680px, centered with margin: 0 auto
  Hub grid: 2 columns (1 column on mobile)
  Section padding: ~48-72px bottom between sections
  Responsive breakpoint: 600px — smaller fonts, single-column, compact padding


SPACING CONVENTIONS
-------------------
  Nav: padding 14px 24px per link, no outer padding
  Hero: 96px top, 24px bottom (64px/20px on mobile)
  UT separator: 48px bottom margin
  Hub cards: 36px 20px
  Updates card: 24px 28px
  Footer: 48px bottom


NOTES FOR FUTURE EDITS
-----------------------
  - All colors are CSS custom properties in :root
  - Two fonts: Determination (local) and Outfit (Google Fonts)
  - Cards use UT battle-box style: black bg, white 3px border, sharp corners
  - The hub grid auto-fits cards — just add more elements
  - The updates section is a placeholder — replace the inner content freely
  - External links use target="_blank" rel="noopener"
  - tracker.html still exists but is not linked from the main site
  - No glassmorphism, no text-shadow glows, no backdrop-filter on content
  - No border-radius on content cards (UT style = sharp)
